## Session du 19 juillet — Bug corrigé ✅

### Bug : Points toujours affichés à 0 après une bonne réponse

**Symptôme** : Dans `TeamScreen`, après avoir répondu correctement, l'interface affichait **0 point** au lieu des points réels.

**Cause racine** : 
- Le backend retourne intentionnellement `points_earned: 0` lors du `submit_answer` (ligne 55 de `backend/main.py`)
- Les vrais points sont distribués par `validate_answers` (appelé par l'hôte)
- `TeamScreen` affichait le `points_earned` de la réponse initiale (qui était 0) sans tenir compte de la mise à jour du score après validation

**Solution implémentée** :
Au lieu d'afficher `answerResult.points_earned` (qui reste à 0), on calcule les vrais points gagnés en comparant le score actuel avec le score avant la réponse.

**Changements dans `frontend/src/pages/TeamScreen.tsx` :**

1. **Ajout d'un état pour capturer le score avant réponse** (ligne 53) :
   ```typescript
   const [scoreBeforeAnswer, setScoreBeforeAnswer] = useState<number>(0)
   ```

2. **Sauvegarde du score avant soumission** (ligne 99) :
   ```typescript
   const handleSubmitAnswer = async () => {
     if (!state?.current_question || !answer.trim()) return

     try {
       // Sauvegarder le score avant la réponse pour calculer les points gagnés après validation
       setScoreBeforeAnswer(state.team_score)
       
       const result = await submitAnswer({
         question_id: state.current_question.id,
         team_id: teamIdNum,
         player_answer: answer.trim(),
       })
       setAnswerResult(result)
       setAnswer('')
       await loadState()
     } catch (err) {
       setError(err instanceof Error ? err.message : 'Erreur lors de la réponse')
     }
   }
   ```

3. **Affichage des vrais points gagnés** (ligne 277) :
   ```typescript
   <p className="mt-2">
     +{state ? Math.max(0, state.team_score - scoreBeforeAnswer) : 0} points
   </p>
   ```

**Comment ça marche** :
1. Avant de soumettre une réponse, on sauvegarde le score actuel de l'équipe
2. Le polling continue en arrière-plan (toutes les 2 secondes)
3. Quand l'hôte valide les réponses, le backend met à jour les scores des équipes
4. Le polling récupère automatiquement le nouveau score
5. L'affichage calcule la différence : `score_actuel - score_avant_réponse` = points gagnés
6. L'interface affiche maintenant les vrais points (200, 400, etc.) au lieu de 0

**Avantages de cette approche** :
- ✅ Pas de changement backend nécessaire
- ✅ Utilise le mécanisme de polling existant
- ✅ Affichage des points en temps réel après validation
- ✅ Simple et élégant
- ✅ Gère aussi le cas des mauvaises réponses (0 points)

## État du projet

### Architecture actuelle

```
Lobby.tsx
  ├─ navigate('/game/:code/host')   → HostGame.tsx  (hôte)
  └─ navigate('/game/:code/team/:id') → TeamScreen.tsx (équipes)

HostGame.tsx flow :
  forceNewQuestion() → setCurrentQuestionApi() → setWaitingForTeams(true) + startPolling()
  WaitingForTeams détecte all_answered → handleAllAnswered() → handleValidateAnswers()
  Hôte voit résultat → clique "Tour suivant" → forceNewQuestion() (efface answerResult)

TeamScreen.tsx flow :
  getTeamState() poll toutes les 2s → voit current_question
  Équipe répond → submitAnswer() → sauvegarde scoreBeforeAnswer
  Polling continue → détecte mise à jour du score après validation hôte
  Affiche answerResult avec vrais points calculés (score actuel - score avant)
  Quand question change (useEffect) → efface answerResult → affiche nouvelle question
```
